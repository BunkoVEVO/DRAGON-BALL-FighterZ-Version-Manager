# DBFZ Version Manager

A C# WPF desktop application designed to make downloading and installing older versions of **Dragon Ball FighterZ** easier.

The goal is to let users select a historical game version and automatically download and install it using Steam depot manifests.

## Features

### Planned Features
- Select from a catalog of historical DBFZ versions.
- Download game files using Steam depot manifests.
- Automate downloads through DepotDownloader.
- Install selected versions into the game's directory.
- Back up the current installation before replacing files.
- Display download progress and installation status.
- Save version information using JSON files.

## Technologies

- **Language:** C#
- **Framework:** .NET / WPF
- **Interface:** XAML
- **Download Tool:** [DepotDownloader](https://github.com/SteamRE/DepotDownloader)
- **Data Storage:** JSON
